# Security Policy

## Supported Versions

Until stable releases are published, security updates are handled on the default branch.

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by opening a GitHub security advisory in this repository.

When reporting, include:

- Description of the issue and impact
- Reproduction steps or proof of concept
- Suggested remediation if known

We aim to acknowledge reports within 3 business days and provide regular updates through resolution.
