# Contributing to DevPilot AI

Thanks for your interest in contributing.

## How to Contribute

1. Fork the repository and create a feature branch.
2. Keep changes focused and well-scoped.
3. Open a pull request with a clear description.
4. Participate in review and address feedback promptly.

## Development Expectations

- Follow existing repository conventions.
- Keep documentation updated when behavior or public interfaces change.
- Add or update tests when test infrastructure exists for your change area.

## Pull Request Checklist

- [ ] Changes are focused and minimal
- [ ] Documentation updated where needed
- [ ] Tests and checks relevant to the change pass
- [ ] No secrets or sensitive data included

## Community

By participating, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).
