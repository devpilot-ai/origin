# Contributing

Thanks for your interest in contributing to Origin.

## Scope

This repository currently contains platform foundation artifacts (architecture, governance, workflows, and standards placeholders).

## Contribution Flow

1. Open or discuss an issue first
2. Keep changes scoped and documented
3. Follow coding standards in `docs/standards/coding-standards.md`
4. Submit pull requests using `.github/PULL_REQUEST_TEMPLATE.md`

## Standards

- Documentation-first changes for architectural decisions
- ADR updates for major technical decisions
- Security-first mindset for all future implementation work

## Code of Conduct

By participating, you agree to follow `CODE_OF_CONDUCT.md`.
